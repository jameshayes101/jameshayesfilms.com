# James Hayes Films website

- `index.html` is the whole site. It must stay at the top level of the repository.
- `images/` holds the five photos the page uses. Keep this folder next to `index.html`.

To publish on GitHub Pages:
1. Create a new repository and upload `index.html` and the `images` folder.
2. Open the repository's Settings, choose Pages, and set the source to your main branch and the root folder.
3. After a minute or two the site appears at the address GitHub shows.
